# Geomagnetic Pro 2025

**Магнітне поле з урахуванням висоти (Altitude)**

---

## Функції

- **WMM2025 + RTDM** — реальний час
- **Висота (м)** — у всіх модулях
- **Теплова карта** — деклінація на заданій висоті
- **Вектори** — GeoJSON/Shapefile
- **Клік на карті** — з введенням висоти
- **Пакет CSV** — `lat,lon,alt`
